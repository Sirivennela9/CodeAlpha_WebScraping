# CodeAlpha - Task 1: Web Scraping

## Project Overview
This project extracts book data (Title, Price, Rating, Availability) 
from a public website using Python Web Scraping.

## Technologies Used
- Python
- BeautifulSoup
- Requests
- Pandas

## How to Run
1. Install libraries: pip install -r requirements.txt
2. Run: python scraper.py
3. Output file books.csv will be created

## Output
Custom dataset of 20 books saved in books.csv
